## How Codex works this list

Codex reviews each URL, records demonstrated differences and completion checks, then makes as many relevant improvements as reasonably possible. There is no fixed improvement count. Complete related work for each URL before moving to the next where practical. Shared fixes must be checked across affected URLs. Record individual changes in [current_batch.md](current_batch.md), with local checks, commits, and required deployed checks.

No URL moves to completed on local evidence alone. Every required URL-pattern endpoint must eventually receive visual confirmation against Rails. Record passes, differences, blocked checks, missing variations, and unfinished checks separately. A request to deploy follows tested commits and a confirmed push. The owner deploys; Codex verifies the loaded revision and checks every recorded change.
